1. Preview your recordings

Select videos in physical recording order. These previews stay in your browser; selecting them does not run inference or upload them.

2. Run the analysis

The models run in a Python workspace. Open the Colab notebook, run its setup cells, then open the generated protected UI and upload both videos there. The files selected above are not transferred automatically.

Launch analysis in Colab ↗

Colab availability and memory are limited; a persistent inference service is not included. The optional visual-language API stage requires separate credentials and may incur charges.

3. Review the output

Choose changes.json or visual_changes.json from your downloaded results. To explore the 3D scene, extract the results archive and open visualization/index.html.
